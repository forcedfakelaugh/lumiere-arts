# What this repository contains

Each edit under `products/<product>/versions/<version>/source/` includes its
Hyperframes HTML timeline, metadata, dependency manifest, images, 1080p working
video clips, music, fonts and local GSAP script. The working `.mp4` clips in
`source/assets/video/` are inputs, so they are intentionally versioned.

V01 and V02 can be edited and rendered from a clone after installing their npm
dependencies. `node_modules` is not committed. On the original Mac it may be a
symlink to a shared installation; that symlink is also excluded.

Not committed:

- Finished videos and other generated files under `exports/` and `renders/`.
- Hyperframes caches, thumbnails, QA screenshots, logs and private chat screenshots.
- The raw 4K camera files in `assets/originals/`. These are not required to render
  the current 1080p edits. Keep a separate backup if you need to rebuild proxies
  or make a higher-resolution master.
- Earlier legacy demos, temporary revisions and Mac compatibility aliases.

`products/01-vung-song-2/assets/originals-manifest.json` identifies the original
client files by relative path, size and SHA-256. Original-name mapping remains
with the local originals. Historical QA metadata may refer to local export paths;
those files are generated by rendering and are not part of this repository.

## Run an edit

```sh
cd products/01-vung-song-2/versions/v02-mot-chi-tiet-nhieu-dien-mao/source
npm ci
npm run preview
```

Requires Node.js 22 or newer.

Use `npm run check` to inspect the composition and `npm run render` to generate
the Full HD MP4 in the version's `exports/` directory. Hyperframes is pinned to
0.8.162. To run V01, use its `source/` directory instead.

The package lock records the dependency tree. The rendering/QA helper scripts
also use `ffmpeg`, `ffprobe`, and Python 3 when invoked separately.
